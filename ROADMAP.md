# Roadmap (owner-curated)

Ideation reads this first. Ideas ladder into a theme below or justify why not.
Edit freely - this file IS the steering wheel.

## Themes, in priority order

1. **Prove the agent engineering by demonstration.** The pipeline/systems story
   as interactive showcase: live case-study cards fed by real telemetry
   (docs/showcase.md contract in swaygent), explorable architecture, the evals
   story. A recruiter should SEE the fleet working, not read about it.
2. **Recruiter conversion.** The 90-second path: land -> understand who this is
   -> see proof -> grab resume/contact. Anything that shortens or strengthens
   that path.
3. **Signature visual moments** - design-first epics through Claude Design,
   always building on the existing warm-paper map language (design-system.md).
4. **Discoverability.** SEO/share polish only when it serves 1-3; never as the
   headline idea.

## Not now
- New sections unrelated to the themes; novelty for its own sake; anything the
  changelog shows was already tried and rejected.
